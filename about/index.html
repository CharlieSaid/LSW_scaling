Lego Star Wars scaling tool: Compare scales against canon ship sizes.

About

Created by BAUFman Bricks and Charlie Said

Official Lego scales are inconsistent across themes and eras. BrickDimensions plots measured Lego sizes against movie and book canon dimensions so builders can see how UCS, Playscale, and BAUFman-scale sets actually compare.

The interactive chart and bidirectional calculator use curves fit to real set data, not a single fixed ratio — so conversions reflect how each scale category behaves across different ship sizes.

How to use it

  • Toggle data points and fit curves for UCS, Playscale, and BAUFman.
  • Scroll to zoom and drag to pan the chart; reset zoom anytime.
  • Use the calculator to convert between in-universe and Lego dimensions for a chosen scale category.
  • Switch units between imperial (in / ft), metric (cm / m), and Lego studs (8 mm pitch) with meters.

Dimensions and fits are estimates for reference — always verify critical measurements yourself. This site is not affiliated with the LEGO Group or Lucasfilm.
